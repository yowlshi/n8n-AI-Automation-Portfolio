# n8n AI Automation Portfolio

## Overview

This repository showcases production-style automation systems built with n8n. The projects demonstrate practical applications of AI agents, Retrieval-Augmented Generation (RAG), voice AI, document processing, business analytics, and customer support automation.

Each workflow was designed to solve real-world business problems while demonstrating scalable automation architecture, API integrations, and AI-driven decision making.

## Featured Projects

### 1. Facebook Messenger AI Inquiry Assistant

An AI-powered customer support assistant that automatically answers customer inquiries through Facebook Messenger using a structured knowledge base.

Key Features

* Automated customer support
* Knowledge-base-driven responses
* Service and pricing inquiries
* FAQ handling
* Multi-language support
* Conversation memory

---

### 2. AI-Powered Invoice Management Agent

An intelligent invoice processing workflow that receives invoices through Telegram, extracts information using OCR and AI, stores records, and generates structured outputs for tracking and reporting.

Key Features

* Telegram-based invoice submission
* OCR text extraction
* AI-powered invoice parsing
* Structured data extraction
* Google Drive storage
* Automated record management

---

### 3. AI Dental Appointment Setter

A voice-enabled appointment scheduling assistant that automates patient booking workflows and calendar management.

Key Features

* AI voice conversations
* Appointment scheduling
* Availability checking
* Google Calendar integration
* Automated booking confirmation
* Patient information capture

---

### 4. AI Sales Data Assistant

A conversational analytics assistant that allows users to query sales information using natural language.

Key Features

* Natural language data retrieval
* Business analytics
* Sales insights generation
* Product performance analysis
* Revenue analysis
* Interactive data exploration

---

### 5. SQL AI Sales Analytics Assistant

An AI agent that generates and executes SQL queries against a sales database to answer business questions and provide data-driven insights.

Key Features

* AI-generated SQL queries
* PostgreSQL integration
* Revenue reporting
* Regional analysis
* Product performance tracking
* Business intelligence reporting

---

### 6. RAG-Powered Employee Handbook Assistant

A Retrieval-Augmented Generation system that enables users to interact with employee handbook documents through natural language.

Key Features

* Vector embeddings
* Semantic search
* Knowledge retrieval
* Context-aware responses
* Supabase vector store integration
* Automated document ingestion

---

### 7. Full Context AI Assistant (Prompt-Based)

An AI assistant that analyzes multiple complete documents by injecting the full document contents directly into the system prompt.

Key Features

- Full-context document analysis
- Multi-document reasoning
- Cross-document comparisons
- Roadmap generation
- Strategic recommendations

---

### 8. Full Context AI Assistant (Prompt-Based: Flexible)

An enhanced full-context implementation designed for greater flexibility and scalability when handling large documents and dynamic knowledge sources.

Key Features

- Flexible prompt architecture
- Dynamic document context injection
- Multi-document synthesis
- Context preservation
- Actionable insight generation

---

### 9. Full Context AI Assistant (Tool-Based)

A tool-driven implementation that retrieves document content through dedicated tools before generating responses.

Key Features

- Tool-based retrieval
- Multi-document reasoning
- Knowledge synthesis
- Context-aware recommendations
- Modular architecture
